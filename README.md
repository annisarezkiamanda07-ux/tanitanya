# TaniTanya — Website Forum Pertanian

Project website tugas berbasis AI dengan tema forum tanya-jawab pertanian.

## Fitur
- Beranda dan statistik pertanyaan/jawaban
- Daftar pertanyaan
- Pencarian
- Filter topik
- Detail pertanyaan
- Menambah jawaban
- Mengajukan pertanyaan
- Preview foto
- Responsive untuk HP dan laptop
- Data demo tersimpan di `localStorage` browser

## Cara menjalankan
Cara paling mudah: buka `index.html` di browser.

Untuk deployment:
1. Upload folder project ini ke GitHub.
2. Import repository tersebut ke Vercel atau layanan hosting statis.
3. Karena project ini tidak membutuhkan server/database eksternal untuk demo, tidak perlu API key.

## Catatan tugas
Project ini dibuat agar dapat langsung dipresentasikan sebagai website yang dibuat dengan bantuan AI. Versi ini sengaja dibuat mandiri sehingga dapat berjalan tanpa konfigurasi Supabase/API key.

Jika dosen meminta backend Supabase secara khusus, project dapat dikembangkan lebih lanjut dengan Supabase Auth, Database, Storage, dan RLS.
