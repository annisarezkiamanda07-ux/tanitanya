# Cara membuat website bisa diakses

## Opsi Vercel
1. Buat repository GitHub baru.
2. Upload seluruh isi folder `TaniTanya_Final`.
3. Masuk Vercel dan pilih **Add New → Project**.
4. Pilih repository `TaniTanya`.
5. Klik **Deploy**.
6. Setelah selesai, Vercel memberikan URL publik.

Tidak ada API key yang diperlukan pada versi ini.

## Opsi paling sederhana
Jika dosen hanya membutuhkan URL website, folder ini juga dapat diunggah ke layanan hosting statis yang menerima folder HTML/CSS/JS.
